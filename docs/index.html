PFFNFL

Reverse-engineered public data pipeline for Pro Football Focus (PFF) + complementary NFL sources.

Purpose

Collect reliable public NFL data (rosters, schedules, depth charts, snap counts where available, player info) for use in backtesting prediction engines.

Focus is on publicly accessible pages. Premium/PFF+ data is intentionally out of scope.

Current Data Collected

  • ✅ 32 NFL Teams (with conference/division)
  • ✅ Rosters (player name, position, basic grades from public pages)
  • ✅ Team Schedules
  • ✅ Weekly Scores / Game links

Quick Start

git clone https://github.com/buffedlizard55-lab/PFFNFL.git
cd PFFNFL
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python scripts/run_scrape.py --season 2026 --type teams
python scripts/fetch_all_public.py

Recommended Complementary Sources

  • nflverse — best free structured data (pbp, rosters, snap counts, injuries)
  • ESPN public endpoints
  • Pro Football Reference
